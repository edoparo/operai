CRM offer numbering can continue from wellD's document system (specs/20261102-crm-offer-document US-8). Settings has an "offer numbering" card per entity that sets the next offer number of the year, so the next new offer is, for example, `0019/2026` instead of `0001/2026`. It can never be set to a number an offer already carries, so references never collide.
